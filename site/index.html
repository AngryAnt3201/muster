MUSTER

build · place · clash

A turn-based army battler. Buy units, place them on your half of the field, press Fight and watch your army play out your plan.

Play in your browser Get the code on GitHub

Free. No install, no sign-up. Best on a phone or a narrow window.

31 units

No grid, no lanes. Every unit steers freely and fights its own way: flankers, chargers, casters, traps, flyers, builders.

Ranked ladder

Eight leagues from Mustering Field to Warlords. Trophies for every win, and a league you reach is yours to keep.

Play your friends

Share a friend code, send a challenge, and fight a live match. The server runs every battle, so the score is the same for both of you.

Six modes

A 60-level campaign with bosses, a Daily Challenge, the Gauntlet, Breakpoint puzzles, Bastion and open Skirmish.

Rivals that think

Rivals test their plans against your board. Tune them yourself in the AI lab, or watch two AIs fight.

Open to build on

The whole game is on GitHub. Clone it, reskin it, rename everything, or write your own client against the match server.

Run it yourself

One command starts a match server and the game on your machine, and opens the Versus screen.

git clone https://github.com/AngryAnt3201/muster.git
cd muster
npm install
npm run play

Needs Node 22 or newer. Add -- --two for a second player in another tab, or -- --tunnel to host for friends anywhere. The public ranked server is invite only: you join with a token.
